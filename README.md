# 🛡️ O Torneio de Ferro 

## Criadores do projetos
- Dayvid
- Will
- Derek
- Arthur

#

É um sistema de combate, honra, tática e aleatoriedade inspirado no mundo medieval-fantástico criado por <a href="http://dayvidsantana.com/">Dayvid Santana</a> para o projeto <a href="https://castle-collis-angelus.vercel.app/">Castle Collis Angelus</a>. Este jogo se passa durante o **Torneio de Ferro e Glória**, um evento que reúne guerreiros de diferentes casas nobres para enfrentar desafios físicos, espirituais e mentais.

## 🎯 Objetivo

Criar um RPG jogável com:
- Tipo de personagens
- Sistema de seleção de personagens
- Eventos aleatórios que afetam o jogo
- Arena de combate
- Personagens canônicos com lore
- Cenários temáticos para os duelos

---

## 📋 Tarefas do Projeto

### 🔨 Tarefas Gerais de Desenvolvimento

- [x] Criação das **classes de personagens**
  - [x] Definir nomes e estilos de luta
  - [ ] Atribuir atributos D&D (STR, DEX, CON, etc.)
  - [ ] Criar habilidades únicas e passivas
  - [ ] Escrever mini-lore de cada personagem

- [x] Criação dos **cenários de combate**
  - [ ] Definir 3 a 5 arenas com efeitos únicos
  - [ ] Associar penalidades ou bônus ambientais
  - [ ] Criar imagens ou descrições visuais das arenas (caso tenha)

- [ ] Implementar a **seleção de personagem**
  - [ ] Interface de escolha (nome, tipo, descrição)
  - [ ] Visualização de ficha de atributos e lore
  - [ ] Botão de confirmação e entrada no jogo

- [ ] Construção da **arena de combate**
  - [ ] Sistema de turnos automáticos com descrição dos acontecimentos
  - [ ] Cálculo de dano
  - [ ] Uso de habilidades especiais
  - [ ] Indicação visual de turno e status

- [ ] Criação de **personagens canônicos**
  - [ ] Nome e história individual
  - [ ] Ficha completa com atributos e classe
  - [ ] Relacionamento com as Casas
  - [ ] Participação no Torneio como NPCs

- [ ] Sistema de **eventos aleatórios**
  - [ ] Catálogo de eventos com efeitos diversos
  - [ ] Lógica para ativação (chance por rodada)
  - [ ] Eventos positivos, negativos e neutros
  - [ ] Como afetam atributos, turnos ou moral

- [ ] Implementar o **sistema de ranking do torneio**
  - [ ] Definir critérios para pontuação (vitórias, derrotas, desempenho)
  - [ ] Criar tabela de classificação atualizável
  - [ ] Exibir posição dos jogadores e NPCs no ranking
  - [ ] Integrar ranking ao sistema de progressão (avançar rounds, eliminar participantes)
  - [ ] Sistema de premiações baseado no ranking final
